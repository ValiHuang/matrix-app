          📖 個人行政秘書系統(PASS) 使用須知

          ⚠️ 提醒：您尚未設定專屬同步金鑰！
          目前系統僅以單機離線模式運作，若清除瀏覽器快取資料可能遺失。

          🔐 1. 重要：請設定高強度專屬同步金鑰

          本系統具備 Firebase 雲端即時同步功能。任何輸入相同金鑰的裝置（電腦、手機、平板）都能同步編輯您的四象限排程、購物清單、記帳與便貼。

          • 設定高強度密碼：請勿使用簡單常見的字詞（如 123456、admin、test 等），強烈建議使用「英文大小寫 + 數字 + 特殊符號」組合，避免他人意外猜到而能查看或修改您的事物排程。
          • 跨裝置隨身同步：在手機或新電腦開啟本系統時，只需在上方「未連線金鑰」輸入同一組密碼，即可無縫載入所有資料。

          💡 2. 使用安全與操作提醒

          • 自建金鑰毋須註冊：直接點擊上方金鑰按鈕輸入即可生效，不用填寫個人帳號信箱，隱私安全無負擔。
          • Google 日曆連動：月曆側邊欄已支援 Google 日曆雙向串接。登入屬於您個人的 Google 帳號授權，其他人絕無權限存取您的日曆。
          • 離線防護 PWA：本系統支援手機安裝（新增至主畫面），在無網路環境下仍能正常記錄，待連網時自動同步。

          Google 日曆連線設定

          請至 Google Cloud Console 建立 OAuth 2.0 Web Client ID，並啟用 Google Calendar API。

          設定提醒：
          1. 在 Google Cloud 建立「OAuth 用戶端 ID」，類型選「網頁應用程式」。
          2. 「已授權的 JavaScript 來源」請填寫目前的網址（例如 http://localhost:5500、http://127.0.0.1:8080 或您的正式網址）。
          3. 複製 Client ID 並貼在上方後點擊「儲存」即可。
